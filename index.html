          GET
          /api/health
          Service health check (public)
        

        

          
No authentication required. Returns HTTP 200 when the database is reachable, HTTP 503 when degraded. Use this with uptime monitors (UptimeRobot, BetterStack, etc.).

          
Response fields

          
statusstring"ok" or "degraded"

          
checks.dbbooleanWhether the Neon Postgres ping succeeded.

          
latencyMsnumberDatabase round-trip in milliseconds.

          
tsnumberServer-side Unix ms timestamp.

          GET
          /api/stats
          Task analytics & counts
        

        

          
Returns aggregate counts and category breakdowns. No task titles or content are returned — safe to expose in dashboards.

          
Response fields

          
totalnumberTotal task count.

          
completed / activenumberCounts by completion state.

          
overdue / dueTodaynumberActive tasks by urgency.

          
upcoming7numberActive tasks due in the next 7 days.

          
completionRatenumber0–100 percentage of completed tasks.

          
byPriorityobject{ high, medium, low } counts.

          
byCategoryobjectCategory name → count map.

          
recentlyCompletedarrayLast 5 completed tasks (id + title + emoji only).

          GET PATCH DEL
          /api/task?id=<id>
          Per-task CRUD
        

        

          
Operate on a single task by ID without replacing the whole list. PATCH only updates the fields you send — unspecified fields are untouched.

          
Query param

          
idstringTask ID (from GET /api/tasks response).

          
PATCH — patchable fields

          
titlestringNew title (non-empty).

          
completedbooleanMark done or undone.

          
prioritystring"high" | "medium" | "low"

          
categorystringCategory label.

          
dueDatestring"YYYY-MM-DD" or "" to clear.

          
descriptionstringOptional task notes.

          GET POST DEL
          /api/keys
          API key management
        

        

          
Create, list, and revoke developer API keys stored in the database. The raw key value is returned only once at creation time — store it immediately. Keys are hashed with SHA-256 before storage.

          
GET /api/keys — list keys

          
Response{ keys: [{ id, name, prefix, createdAt, lastUsed }] }

          
POST /api/keys — create key

          
namestring (required)Friendly name for the key (max 80 chars).

          
Response{ id, name, prefix, createdAt, key } — key is the full plaintext, shown once only.

          
DELETE /api/keys?id=<id> — revoke key

          
idstringKey ID from the list.
